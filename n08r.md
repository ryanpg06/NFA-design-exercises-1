3. Challenging moments / mistakes

010101010 would get accepted but 0101010 would get rejected.
This was a mistake that I ran into when trying to figure out what happens if you reach the ending (10) but there is still more to the string. I knew that if it was a 0 I had to go back to q2, but I also thought if it was a 1, it would have to go back to q2 as well. Then, I realized that it would delay it by a step and only allow an even number of "10"s, when in reality, both even and odd amount of "10"s should be accepted.
